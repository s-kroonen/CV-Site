## Proposed structure on the site

- **Group** = a category on each project (shown as sections or a filter on the
  Projects tab). Groups 1-4 above, plus "Studieprojecten / Coursework" for 5.
  Forks (6) either skipped or in a small "Open source / security" group.
- **Links**: education items can't hold projects, so the coursework projects
  hang off one experience ("Student - HBO-ICT, Avans Hogeschool: study
  projects") which is linked to the education item. Personal projects stay
  unlinked, or link to an experience if one of them was done at a job/internship.
- **Basic info per project** (what the import would fill in): title, link to the
  repo, one-line summary, tech stack tags, period, group. Longer descriptions and
  screenshots can be added later in the admin.
